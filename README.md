# heritage.iradgov.org

Mirror of the website of the **Heritage Protection Service** of Irad and its State Register of Monuments of History and Culture: [heritage.iradgov.org](https://heritage.iradgov.org/).

Texts and images belong to the site's owner; questions about monuments, permits and finds go to them, not to the mirror.

Part of the [Irad Web Mirror](https://github.com/IRAD-WEB-MIRROR).
